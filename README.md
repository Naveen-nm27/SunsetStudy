## 🚀 Installation & Setup

Follow these steps to set up the project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Naveen-nm27/SunsetStudy.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd SunsetStudy
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Set up environment variables**
   Create a `.env` file in the root directory and add the necessary environment variables (e.g., database connection string):
   ```env
   PORT=3000
   MONGO_URI=your_mongodb_connection_string
   ```

5. **Start the development server**
   ```bash
   npm start
   ```
   *Note: This will start the server using `nodemon`, which automatically restarts upon any file changes.*
